Writing one of these? Check it first

Before you submit, you can see what a reproducer would find in your own archive — or in the model and simulation document as they sit in your directory. It reads your files, runs no model, reaches no verdict, and issues no certificate.

git clone https://github.com/clay-good/reprolith && pip install -e ./reprolith
reprolith archive-check paper.omex --claims my_claims.json
reprolith archive-check --sedml paper.sedml --model paper.xml --claims my_claims.json

With --claims — the results your paper reports — it also answers the question nothing in your archive can: does the experiment you ship actually run them? Every file can be valid, and the run can complete, while producing a neighbouring arm nobody published.
