# Third-party content redistributed under `datasets/`

`LICENSE-DATASET` (CC BY 4.0) covers the data **Reprolith produces** — certificates, catalog
entries, dossiers, bundles, agreement reports, and the registry page. It does **not** cover the
model files and reference data redistributed here, which keep their upstream licenses. Some are
more restrictive than CC BY, so check this list before redistributing or building on them.

| What | Where | Upstream | License |
|---|---|---|---|
| Genome-scale metabolic models (`iAF1260`, `iEK1008`, `iIT341`, `iJO1366`, `iLJ478`, `iMM904`, `iNF517`) and `e_coli_core` | `datasets/constraint_based/` and `datasets/constraint_based/cross_validation/` | [BiGG Models](http://bigg.ucsd.edu/) | **Academic and non-profit use only.** BiGG's own license covers its source code under MIT but not its model content; commercial use requires contacting UCSD Technology Transfer. See <http://bigg.ucsd.edu/license>. |
| Curated kinetic and PK/PD models (`BIOMD*.xml`) | `datasets/kinetic/`, `datasets/worked_examples/`, `tests/fixtures/` | [BioModels](https://www.ebi.ac.uk/biomodels/) | CC0 1.0 (public domain dedication) for curated-branch models. |
| Boolean network rules used as logical-class references | `datasets/logical/cross_validation/` | Derived from published models via [CANA](https://github.com/CASCI-lab/CANA) | The rules trace to their source publications, cited per model in that directory's README; CANA itself is MIT. |
| Quoted table rows from one source paper, and a survey of its table captions and counts | `datasets/manuscripts/` | [PLOS ONE 10.1371/journal.pone.0249594](https://doi.org/10.1371/journal.pone.0249594) (© 2021 Zake et al.), read from the open-access full text via Europe PMC | CC BY 4.0. Only the rows a committed claim cites are stored, plus the paper's Table 3 of partition coefficients, which `datasets/pkpd_parameters.json` pairs with the deposited models' own parameters — so a test can check both a reference value and a model input against the paper without the network. |
| A survey of which candidate papers are reachable (`candidate_survey.json`) | `datasets/manuscripts/` | Model names and accessions from [BioModels](https://www.ebi.ac.uk/biomodels/); open-access status and PubMed/PMC identifiers from [Europe PMC](https://europepmc.org/) | Identifiers and counts only — no paper text is stored, and a count of how many numbers a table prints reproduces nothing of it. Model names are BioModels metadata (CC0 1.0). One paper's open-access full text was read to produce those counts and none of it is kept. |
| Reference outputs (`reference_growth.json`, FROG components, libRoadRunner trajectories, CANA attractor signatures) | `datasets/*/cross_validation/` | Generated by COBRApy, libRoadRunner, and CANA from the models above | Facts computed from the upstream models; they inherit the model's terms. The generating tools are GPL-2.0-or-later (COBRApy), Apache-2.0 (libRoadRunner), and MIT (CANA), and none of their code is redistributed here. |

Every model file's provenance — upstream repository, accession, and source publication — is
recorded in the README of the directory holding it, and travels inside each certificate's
`source_location`. If you spot an attribution or licensing error here, please open an issue: this
file is a good-faith summary, not legal advice.
