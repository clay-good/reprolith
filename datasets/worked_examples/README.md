# Worked example — metformin PBPK reproduction

A real, end-to-end Reprolith certification of a published model, start to finish, on real data.
It is the first concrete instance of the bootstrap pipeline producing an honest, qualified
verdict — a walkable artifact a stranger can follow without Reprolith internals.

## The paper and the claim

- **Model:** Zake2021, PBPK model of metformin in humans, single oral dose
  ([BioModels BIOMD0000001028](https://www.ebi.ac.uk/biomodels/BIOMD0000001028), CC0).
- **Paper:** Zake et al., *PLOS ONE* 2021, [doi:10.1371/journal.pone.0249594](https://doi.org/10.1371/journal.pone.0249594) (open access).
- **Claims checked** (reference values from the manuscript, not from re-running the model, so
  the checks are not circular):
  - **500 mg** oral dose → plasma **Cmax 6.2 nmol/mL** (Zaharenko dataset, Table 4).
  - **1000 mg** oral dose → plasma **Cmax 11.2 nmol/mL** (Chung dataset).

## What Reprolith found

Run under the pinned COPASI engine:

- **500 mg — reproduced cleanly.** The model as shipped gives Cmax 6.07 vs reported 6.2 nmol/mL
  (**2.2 %**), with no Reprolith assumption: the model's default dose already encodes the salt
  conversion.
- **1000 mg — reproduced, but only under a load-bearing assumption.** Simulated Cmax 11.25 vs
  reported 11.2 (**0.4 %**) — after converting the stated 1000 mg **HCl salt** to the 779.9 mg
  **free base** the model consumes. Taken naively (1000 mg straight in), it overshoots by
  **26 %** and fails.

Reprolith infers the free-base convention from the model's own default (389.92 mg = 500 mg HCl
as free base). Because the 1000 mg reproduction rests entirely on that assumption, its claim is
**reproduced (assumption-qualified)**, and the overall verdict is **partially-reproduced** — a
clean claim and a qualified one, never rounded up. Reprolith takes no unqualified credit for
its own guess.

This is the whole thesis in one case: the model *does* reproduce its paper, but reproduction
hinges on an under-specified detail (the salt-form dosing convention), and an honest system
surfaces that detail rather than hiding it.

## Files

- `Zake2021_metformin_human_single_PO.xml` — the CC0 model artifact.
- `Zake2021_metformin_human_single_PO.sedml` — the simulation document BioModels ships beside it,
  as downloaded. Not written by Reprolith, and not what the certificate ran.
- `metformin_reconstruction.omex` — **the reproduction itself, as a runnable COMBINE archive.**
  The model, plus the SED-ML Reprolith writes from its own published reconstruction bundle: one
  task per claim, the 24-hour window at 480 steps, the plasma output each reads, and the 779.9 mg
  free-base dose the 1000 mg claim sets. That override is the reason this file exists — it is what
  separates the two claims, and it used to live only in Reprolith's JSON record. Open it in any
  SED-ML tool; no Reprolith needed.
- `metformin_reproduction_certificate.txt` — the rendered certificate.
- Reproduced by `tests/test_worked_example.py` (needs the `engine` extra). The archive is
  regenerated by `python scripts/export_worked_example_archive.py` and its bytes are deterministic,
  so `tests/test_export.py` fails if the committed copy drifts from what the exporter produces.

The archive carries the run, not the verdict: which scalar is read off each trajectory (`cmax`) and
which engine computed the answer are the certificate's statements, and the certificate is the file
that expires when a solver changes.

## Scope and caveats

The certificate attests only to computational reproducibility, never biological or clinical
validity. The claim value (11.2 nmol/mL) was read from the paper text; a fuller ingestion would
cite the exact table/figure and check more than one claim. This is one worked example, not the
full blind test-set run.
